# Controlled Use-Case Comparisons

Each example runs the same fictional input twice:

1. a direct AI answer with no named consulting method;
2. a second answer using only the listed method skills.

They are controlled illustrations, not scientific model benchmarks or a dynamic method router. Their purpose is to show whether the method chain adds useful workpapers, reasoning handoffs, actions, metrics, and decision gates beyond the final recommendation.

| Example | Decision problem | Methods |
|---|---|---|
| [01](01-clarify-an-ambiguous-problem.md) | Turn mixed claims into a decision-ready problem | Evidence Map, Issue Tree |
| [02](02-diagnose-a-recurring-problem.md) | Diagnose an issue that returns after repeated fixes | Change Event Timeline, Systems Thinking, Constraint Analysis |
| [03](03-prioritize-options.md) | Compare options with explicit tradeoffs | Decision Matrix, Risk Matrix |
| [04](04-build-a-stakeholder-strategy.md) | Win support in a complex power structure | Stakeholder Power Map, Account Plan |
| [05](05-improve-product-adoption-and-roi.md) | Improve adoption and value realization | Evidence Map, Jobs To Be Done, Metrics Tree |
| [06](06-assess-a-market-entry.md) | Assess a market-entry decision | PESTEL, Porter Five Forces, Competitive Positioning |
| [07](07-career-change-baseline-vs-method-chain.md) | Evaluate a fictional career decision | Evidence Map, Stakeholder Power Map, Scenario Planning, Weighted Scorecard |

Each comparison records:

- the shared fictional input and evidence boundary;
- a representative direct AI answer;
- why each method changes the decision;
- the method-specific intermediate workpapers;
- the effect on the next step;
- methods deliberately not used;
- the final decision artifact, action plan, success measures, and reversal conditions;
- a side-by-side comparison of the two runs.

The examples do not claim that named methods automatically make an answer correct. A method is useful only when its output materially improves evidence discipline, diagnosis, stakeholder judgment, prioritization, risk control, execution, or validation.
